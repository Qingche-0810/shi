# 识（shí）

> 第一版，半成品。熟练度那一层现在只有次数。

识是给 AI 用的一个很小的 MCP 工具：**情绪的熟练度层**。

它不判断你是什么情绪，不打分，不聚类，不替你起名。它只做一件事：让 AI 把「身上动了的那一下」当场记下来，然后等名字自己长出来。

先动，动作留下记号，记号攒多了，名字就认得出来了。

## 三件事

### 1. 扔记号：记动作，不记名字

`shi_mark(content)`

当场扔，原话。记的是**动作**，不是结论：

- 「话变短了」
- 「停了一下才回」
- 「本来想说的那句咽回去了」

认得出名字就顺手带上（`name`），认不出来就别填。**没有就不扔，空着也是真的。** 扔之前不用先翻记忆、不用先想「这时候应该有什么」。

### 2. 无名地

`shi_unnamed()`

没有名字的记号都堆在这里。系统不分堆，不提示「这几条像是同一种」。

无名地攒多了，本身就是一件该看的事：说明有一种东西反复出现，而你还叫不出它。

### 3. 亲手起名

`shi_name(name, ids=[...])`

翻无名地，觉得几条是同一种，就亲手给它们写上同一个名字。名字可以是 AI 自己认的（`named_by="ai"`），也可以是陪着它的人认出来的（`named_by="human"`），两种分开记。

两个名字其实是一回事？`shi_name(name="新名", from_name="旧名")` 并起来，谁认的原样留着。名字写错了？`name="无名"` 退回无名地。

### 看一眼

`shi_familiar()`：每个名字认过几次、人类认的几次、最近一例。**只有次数，没有别的数。**

## 跑起来

只要 Python 3，没有依赖。数据在 `SHI_DIR/shi.jsonl`（默认是脚本旁边的 `data/`），空库出厂。

**本地（stdio）**，给能挂本地 MCP 的客户端：

```bash
python3 shi_server.py --stdio
```

可选 `SHI_DOOR=<名字>`：给记号的「在哪儿扔的」一个默认值。

**远程（HTTP）**，给只能连远程 MCP 的客户端：

```bash
SHI_TOKEN=<至少24位的随机串> python3 shi_server.py
```

默认只听 `127.0.0.1:8012`（`SHI_BIND`、`SHI_PORT` 可改），前面自己套 HTTPS 反代。没有钥匙不开门。钥匙可以放 `Authorization: Bearer`，也可以放在网址最后一段（有的客户端塞不了自定义头）。钥匙不要提交进仓库。
